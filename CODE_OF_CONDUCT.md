# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, argue about the work and not the person, and assume good faith.
Harassment and personal attacks are not tolerated.

Report a problem to the maintainers privately through the repository's security advisory
form (Security → Advisories), marked as a conduct report. Reports are kept confidential.
